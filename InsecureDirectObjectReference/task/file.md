# WebGoat: Insecure Direct Object References (IDOR)
При перегляді профілю можна помітити різницю між тим, що реально показується у браузері, та тим, що повертає сервер у "сирій" відповіді ![alt text](image.png)

Посилання на профіль має формат: /WebGoat/IDOR/profile/{id}. Змінивши `id`, можна отримати доступ до іншого профілю ![alt text](image-1.png)

За допомогою Burp Suite Intruder запускаємо перебір ідентифікаторів користувачів ![alt text](image-2.png)

При правильному `id` сервер повертає дані іншого користувача ![alt text](image-3.png)

Використовуємо PUT/POST запит для зміни атрибутів профілю.  
Спочатку знижуємо роль до 2 ![alt text](image-4.png)

Знижуємо роль до 1 ![alt text](image-5.png)

Завдання пройдено! ![alt text](image-6.png)
